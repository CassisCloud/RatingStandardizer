Custom Rating Rules

Use custom rules when your metadata contains ratings that are not built in. Alias matches exact rating text such as KR-15 or KMRB-15. Regex matches a pattern such as ^BR-(\d{1,2})$. Treat as is the internal minimum age. Age group is only for Regex rules and tells the plugin which capture group contains the age; use group 1 for ^BR-(\d{1,2})$.
Advanced fields are optional: Conservative overrides age in safer mode, Lenient overrides age in relaxed mode, and Restriction stores the rule type for history and future filtering.
